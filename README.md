# Git Assignment - triggor


    a. What is an issue?
An issue works like an item on a TODO list. They are used to track bug reports, new features and enhancements, and anything else you need to discuss with your team.

    b. What is a pull request?
A pull request is a request to merge your modifications to code with the current branch HEAD. It allows for code review and discussion before the merge.

    c. Describe the steps to open a pull request?
You need to navigate to the repository, create a separate branch, commit changes, push them to GitHub and request to pull them together with another branch through GitHub interface.

    d. Describe the steps to add a collaborator to a repository (share write permissions)
You need to go to "Manage access" section in the repository settings and add a username you wish to invite.

    e. What is the difference between git and GitHub?
Git is a version control technology name, while GitHub is one of the products implementing that technology. 

    f. What does git diff do?
It compares line by line different versions of the same files in different commits or between working directory and staging area.

    g. What is the main branch?
It is a default branch, the production version of code.

    h. Besides our initial commit if it is a new repository, should we directly push our changes directly into the main branch?
Typically no, if we work in a team.
